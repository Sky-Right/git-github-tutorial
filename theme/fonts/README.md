# Original workshop fonts

These are the same font families referenced by the original workshop stylesheet, bundled for offline use. The font files are unmodified.

- Droid Serif 400/700: digitized data copyright © 2007 Google Corporation; Apache License 2.0. The font's name table identifies that license. Its archived Google Fonts metadata also declares `APACHE2`: https://github.com/google/fonts/blob/5fb32282c5969930c4268483ffa5664680bf73c8/apache/droidserif/METADATA.pb
- Inconsolata 400/700: copyright 2006 The Inconsolata Project Authors; SIL Open Font License 1.1. See `Inconsolata-OFL.txt`.
- Font files were retrieved on 24 October 2026 from the Google Fonts CSS API: https://fonts.googleapis.com/css2?family=Droid+Serif:wght@400;700&family=Inconsolata:wght@400;700
- Droid Serif license text: https://www.apache.org/licenses/LICENSE-2.0.txt
- Inconsolata license source: https://github.com/google/fonts/blob/main/ofl/inconsolata/OFL.txt

Keep both license files with redistributed font files. The HTML build embeds these local fonts; playback makes no Google Fonts requests.
